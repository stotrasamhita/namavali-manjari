`_divyasthaniya_` files list names by *divya sthāna* (the deity's sacred/divine places) rather than a straight name list. Where two files share the same title, they're distinct nāmāvaḷis from different sources, not duplicates.

Six of these files aren't currently `\input` by the master `nAmAvalis.tex` (they're still built individually into the per-deity PDFs under `../namavalis-pdf/`, just not assembled into the compiled book): `Durga_108.tex`, `Ganesha_108.tex`, `Ganga_108_2.tex`, `Kamakshi_108.tex`, `Kaveri_108.tex`, `Vyasa_108.tex`.
